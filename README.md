# Friendship-Day
A production-style animated friendship storybook for Giggles and Siddhant.

Open `index.html` in a modern browser.

Tech:
- HTML5 / CSS3 / ES6
- GSAP + ScrollTrigger CDN
- IntersectionObserver
- CSS Grid / Flexbox
- Responsive 320px to 4K
- Reduced-motion support
- SEO + OpenGraph metadata
- Fairy night mode
- Web Audio ambient music toggle
- Scroll progress
- Animated chat, globe route, movie night, letter and final hug

The assets folder contains reusable SVG illustration assets for future swaps or a version that loads external illustrations.
